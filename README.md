# Termux Learn

A gamified mobile app that teaches Termux (Android terminal) from beginner to advanced, with a simulated terminal for safe practice.

## Features
- 📚 Structured lessons (beginner → advanced)
- 🖥️ Simulated terminal — practice commands safely
- ✅ Progress saved locally
- 🎯 Real Termux command validation with hints

## Run locally
```bash
npm install
npx expo start
